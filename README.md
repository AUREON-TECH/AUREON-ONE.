# AUREON One

Painel inicial de pautas e produção de vídeos para YouTube, TikTok e Instagram.

## Estado atual

- Interface responsiva e fila de pautas
- Status: ideia, em produção, revisão e publicado
- Armazenamento local no navegador (sem backend)

## Próximos passos

Autenticação, banco de dados, radar de tendências, pesquisa com fontes, roteiros, geração de áudio e vídeo, revisão humana e integração oficial de publicação.

Abra `index.html` no navegador para testar. Não há integração com IA nem postagem automática nesta versão.
